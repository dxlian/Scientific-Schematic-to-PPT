# 将“大致指令”写成可执行的绘图规格

先按面板写下想证明或解释的现象。例如“左图展示裂隙中流体方向，右图显示突破时间”。识别输入和输出，再为每个科学问题选择合适的几何或坐标轴。简图可把这些决定直接写入原有 design.md；数据图的最小可执行格式见 [示例规格](../assets/data-example.json)。

| 需锁定的内容 | 从输入推断或需要澄清的情况 |
| --- | --- |
| 样式参考 | 记录文件、面板、画布裁框、要保留的部分。区分“重画此图”“换成我的数据”“只参考配色”。 |
| 数据 | 记录文件、工作表、列、原始行序、仪器单位、系列与实验条件。说明有无重复测量，SD、SEM、CI 或设备不确定度如何得到。 |
| 尺寸与输出 | 单栏默认 80 mm，双栏默认 170 mm；PPT 默认沿用原画布或目标幻灯片。需要数值表可编辑时选择原生图表项目。 |
| 注释 | 指定全局或局部峰值、阈值、上穿/下穿或第几次过线、分析区间、是否允许插值、拟合模型和数据处理。缺失影响结果时给出选项。 |
| 样色和字体 | 记录背景、主对象、强调对象和边界的角色色；选色来源为用户、参考图或色库 ID。混排字体分槽设置。 |
| 验收 | 用户图与新表同源时比较数值及版式。数据集不同则核对各自可比的几何与数值，标注替换导致的位置变化。 |

举例，“照这张应力图做，标出峰值和破坏阶段”可以先锁定原图的面板、轴、相位颜色。若表内有多个相同的最高观测，给出位置供选择；若未说明破坏阶段从哪一行开始，先绘制可确定的部分，在确认边界后加阴影。样本分组不明时保留各条原始曲线。

## 组合图交付

1. 确定完整画布的物理尺寸和每块面板边界，预留轴刻度与图例空间。用同一比例安排字号、线宽和颜色。
2. 示意图按原生 PPT 流程生成。定量面板由实际数据绘制。组合预览时，使用相同尺幅的图层，标明哪些元素来自实测图像。组合 PPT 有示意图时按最终合成预览确认。
3. 期刊矢量拼版使用 `python scripts/compose_panels.py layout.json --out out/combined-01`。例如 `{"size_mm":[170,85],"panels":[{"file":"apparatus.pdf","page":1,"box_mm":[0,0,80,85]},{"file":"curve.pdf","box_mm":[85,0,85,85]}]}`。矩形由左上角起按毫米给出 x、y、宽、高，面板等比居中放置，页码从 1 开始。交付矢量 PDF、实际渲染的 600 DPI PNG 及各面板源文件。复查因等比缩放造成的字号变化。
4. PPT 中需要双击改数据时，创建带嵌入工作簿的 PowerPoint 原生图表并核对系列和行数。内置场景构建器负责原生形状，原生图表可用 python-pptx 等能写图表与嵌入工作簿的后端。只需编辑外观时，可在支持 SVG 的 PPT 版本置入矢量面板并同时交付绘图脚本；嵌入 SVG 通常是一个对象。记录图表/工作簿、原生形状、嵌入矢量和实测位图各自的编辑范围。
