# 用户参考图复绘

先确定用户希望保留什么。“按这张图复绘”默认保留原图布局、可辨识颜色、对象与标注。“用我的数据画成这个风格”沿用视觉设计，按用户数据重算曲线和标注。“参考这个色调”只提取配色。用户明确指定的字体、目标尺寸和科学修正写入 `design.md`。中文默认宋体（SimSun），英文默认 Times New Roman。

## 锁定参考与数据

1. 以像素记录原图宽高、有效裁框、面板边界、坐标区、图例、箭头端点及关键外形。记录曲线样式、线宽、点型、轴刻度、留白与堆叠顺序。优先使用用户提供的矢量或原始高分辨率图；低清文字有歧义时保留疑点。颜色从同一角色的多个平坦内部点取样，保留颜色与物理含义的映射。像素色受抗锯齿、压缩及色彩配置影响。
2. 对图与表分别注明职责。表内数值、单位、组别、重复测量、误差定义和拟合条件决定数据层；图提供版式和样式。建立“原图系列 → 文件/表/列 → 单位 → 图例/样式”对应关系。发现数值冲突时记录差异；新数据导致的峰位变化按表呈现。只有图且明确要求提取近似数据时，以坐标刻度标定，记录轴型、标定点和数字化不确定性。无法读清的量保留缺项。
3. 机械复绘时，使用同一裁框的纵横比，在毫米画布上按比例换算像素位置。元素坐标按 `x_mm = (x_px − crop_left) × width_mm / crop_width` 和对应的纵向公式换算。把关键对象的边界、箭头两端、曲线地标、误差线端点及预定容差写入 `fidelity.json` 和设计记录。误差容许值依据原图分辨率、线宽和最终印刷尺寸设定。更换数据的项目只将应保留的布局和样式地标纳入图像对齐评价。

## 预览与重建

对需可编辑 PPT 的示意图，按原流程注册参考图和数据为输入。使用实测几何绘制预览；纯数据层由选定绘图引擎生成，组合图按最终尺寸合成预览。沿用 `workflow.py preview → approve → build_pptx.py` 的版本记录与审批。用户已明确指定原图本身作为最终重建依据时，可以将该原图作为预览注册，并按原流程记录对该版本的明确确认。逐对象保留文本、曲线、箭头及分组；实测图像、组织照片等保留其真实来源并说明编辑范围。需要在 PowerPoint 的数据表里修改数值的图，选择原生图表后端，交付时写明图表、矢量或图像各自的可编辑范围。

## 两次对应检查

- 将最终文件实际渲染为 PNG。对照批准预览检查对象与标注；另对照用户原图检查已承诺保留的版式、几何、色彩和标签。参考源和批准预览相同时一次比较即可。同一裁框/纵横比可用半透明叠图检查边界错位；`regions` 复用 [fidelity-review.md](fidelity-review.md) 的归一化框。留白或裁框不同时，先根据边框、面板角点等明确依据登记裁框；避免为追求表面分数而拉伸图形。
- 根据数据表逐系列核对行数、单位及变换，重算关键注释；含对数轴时按对数坐标验证阈值和坐标映射。对峰值、阈值与置信区间等同时核对记录值、面板位置和引线落点。只有原始数据相同的系列才逐点比较原图的曲线轨迹。
- 保存局部差异及修复记录，例如原图面板边距、实测边距、容差及结果；另列替换数据、指定字体造成的预期变化。缺项、错标或数据来源不明要在交付前修正，未验证项单独说明。
