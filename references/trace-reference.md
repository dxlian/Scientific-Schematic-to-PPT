# 从本地参考图描摹可编辑轮廓

对已有装置、界面或材料层示意图，先裁到一个有明确含义的局部。脚本把颜色区域转换为原生 PPT 自由曲线，保留孔洞，把同色的微小碎片合成复合路径。它输出待核对的 `scene.json`，可接入现有的示意图审核和 PPT 构建流程。

```bash
python -m pip install Pillow numpy opencv-python-headless
python scripts/trace_reference.py source.png --crop 80 35 640 390 --width-mm 80 --out draft/scene.json
```

依赖只用于描摹。若环境已安装提供 `cv2` 的 OpenCV，无需并装另一个发行包。输入为单帧本地图像，例如 PNG、JPEG 或 TIFF。已经裁好的图片可省略 `--crop`。裁框按 EXIF 方向校正后的原图像素填写，包含左、上边界，右、下边界取到最后一列或行之后。脚本按所选图块的原始长宽比计算物理高度。透明区域默认铺白；如需其他底色，可设 `--matte F3F4F6`。

| 参数 | 默认值 | 调整依据 |
| --- | ---: | --- |
| `--max-edge` | 480 | 描摹网格最长边，单位为像素。细线断开时可提高至 720 或 1024，检查自由曲线数目和编辑流畅度。 |
| `--colors` | 24 | 色数上限。少色图在工作网格上保留精确色值。连续色调可试 32 色；照片、噪声和渐变会产生大量轮廓。 |
| `--epsilon` / `--min-area` | 0.23 / 0.30 | 轮廓简化距离与最小面积，分别以工作网格的像素、平方像素计。增大时检查小孔、引线及细部。 |
| `--seam` | 0.42 | 同色描边宽度，以工作网格像素计。出现细白缝时可试 0.65；细孔被覆盖时可减小或设为 0。 |

1. 在 `trace_review` 核对来源哈希、裁框、工作网格、参数及保留下来的形状数。打开原图确认材料层、孔洞、箭头方向、邻接关系及有效边界。色组对应颜色，代表某一科学部件的多个形状可以重新编组。
2. 图中已有文字会成为轮廓。确认拼写、上下标、单位与目标位置，移除或遮盖该处旧字，在场景中添加原生 `text`。中文使用宋体，英文使用 Times New Roman。文字与背景图形交错时，可按已确认的词表在旁边做原生图例，并明确原位小字仍需复核。
3. 将已核对的草稿交给现有审核流程，按批准版本构建，实际渲染并逐区对照。原始曲线、统计标注和坐标数值需要作者数据或经校准的读图依据。像素吻合度只用于比较视觉差异。[示意图审核流程](schematic-workflow.md) · [场景格式](scene-format.md)
