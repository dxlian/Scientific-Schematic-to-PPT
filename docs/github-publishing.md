# Repository Description

## 简介

从研究材料到逐元素可编辑的学术示意图 PPT：预览确认后重建原生文字、曲线、箭头和分组，附十二个工科案例。

## Description

Turn research materials into native editable PowerPoint schematics. Review the design, then rebuild text, curves, arrows, and groups. Includes twelve engineering examples.

## Topics

`scientific-illustration` `academic-figures` `powerpoint` `pptx` `editable-diagrams` `codex-skill`

## 发布介绍

我把制作学术示意图的过程整理成了一个可复用的 skill：先读懂材料，再设计整体画面，预览确认后重建为可编辑 PPT。

它保留简洁的学术风格，但不省略必要的结构、连接关系和局部细节。适用于研究背景、实验装置、机制图和算法架构等不同场景，也便于在后续修改中继续调整文字、曲线和组件。

交付的不只是一张图片：文字、箭头、曲线和部件分别成为原生 PPT 对象，可以直接修改、移动、重新配色或取消组合后调整。每个展示案例都附有独立 PPT 和场景文件，便于查看和复用。

## Introduction

I built this skill around a complete workflow: understand the research, design the schematic, review an image preview, and rebuild the approved figure as native PowerPoint objects.

The result is a figure you can keep working with. Revise text, move components, change colors, edit curves, or ungroup a structure to adjust its details. Twelve engineering examples include individual editable presentations and scene files, alongside a bilingual guide and a community gallery.
