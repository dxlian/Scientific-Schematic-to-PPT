# 跨学科图例

我选取了 12 篇不同工科方向的研究，围绕各自的结构和机制独立设计示意图。它们使用相近的字体、线条与配色，但不套用同一种构图。

以下十二个案例均提供**原生可编辑 PPT**与场景文件，展示图为 PPT 的实际渲染。可以直接编辑文字、曲线、箭头和各级部件，也可以取消组合后修改局部。示意图不替代论文原始数据；结构比例与符号数量不表示实测值。
