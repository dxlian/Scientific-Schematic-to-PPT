# 社区案例

[English](community-gallery.en.md) · [返回首页](../README.md) · [内置案例](gallery.md)

我希望这里不仅展示内置图例，也能积累不同研究领域的真实使用作品。欢迎分享你用这个 skill 完成的示意图，以及有用的设计经验。

**[提交你的案例](https://github.com/dxlian/Scientific-Schematic-to-PPT/issues/new?template=share-your-figure.yml)**

## 如何提交

1. 打开提交表单，填写案例名称、学科和这张图要说明的问题。
2. 在 Issue 中附上清晰的预览图，并提供可编辑 PPT 的公开下载链接。也可以补充场景 JSON；不要提交宏、可执行文件或访问令牌。
3. 简要说明使用的 skill 版本、关键指令、人工修改，以及哪些部分为原生对象、哪些保留为图片。
4. 填写署名方式、文献来源和作品许可，确认内容可以公开分享。

论文尚未发表、涉及保密项目、个人信息或第三方授权不明的内容，请不要上传。无需公开完整论文、实验数据或私人对话记录。

## 如何收录

我会核对提交的信息、来源与分享许可，并查看预览和文件的可编辑范围。通过后，在这里展示作品，并链接到原提交、作者和文件。收录前需要调整时，我会在 Issue 中说明。

投稿不会自动进入仓库，也不会自动执行任何上传的代码或宏。科学准确性仍由作者负责，收录不代表对论文结论的独立验证。

## 精选作品

社区案例正在征集中。收录后，每个条目将展示预览图、研究领域、作者署名、可编辑文件、原始提交链接及许可。

## 署名与许可

作品版权和署名归其作者。提交表单中的展示授权仅用于在本项目中展示预览和描述，并链接到作者提供的文件；完整文件的再分发或使用范围遵循作者明确声明的许可。未明确授权的内容不会进入展示页，社区作品也不会自动改为 MIT 许可。

修改署名、更新下载链接或申请撤下展示，可在原 Issue 中说明。
