# 原生可编辑学术示意图 / Native editable academic schematics

我把阅读研究材料、设计示意图和制作可编辑 PowerPoint 整理成了一套完整流程：先审阅图片，再将确认的设计逐元素重建为 PPT。

- 原生文字、箭头、曲线、区域和分组，可在 PowerPoint 中继续修改。
- 十二个工科案例，提供独立 PPT、合集、场景 JSON 和实际渲染图。
- 中英文使用说明，明确可编辑范围与图像保留方式。
- 社区案例投稿入口，保留贡献者署名和作品许可。

名称含 `-skill-` 的 ZIP 是轻量安装包；完整 ZIP 包含展示案例。校验值见 `SHA256SUMS.txt`。

## English

I built a complete workflow for interpreting research, designing academic schematics, and creating editable PowerPoint files. Review the image first, then rebuild the approved design element by element.

- Native text, arrows, curves, regions, and groups that remain editable in PowerPoint.
- Twelve engineering examples with individual PPT files, a combined deck, scene JSON, and actual renders.
- Bilingual guidance on editable elements and retained source images.
- A community submission form with contributor attribution and declared licenses.

The ZIP containing `-skill-` is the compact installation package. The full ZIP includes the example gallery. Checksums are provided in `SHA256SUMS.txt`.
