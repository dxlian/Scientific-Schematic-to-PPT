# v0.4.0 科研示意图配色、参考图复绘与定量标注

继续使用 `$scientific-schematic-to-ppt`。示意图先批准预览，然后重建原生 PPT；数据图依据源表直接绘制。组合图按面板选择引擎。

- 13 个主题的 81 个角色色块，可以按对象或用户指定的参考色调用。公开论文图页的采样依据包含 67 篇原始研究、15 种期刊和 70 个区域。[配色色卡](https://github.com/dxlian/Scientific-Schematic-to-PPT/blob/v0.4.0/docs/palette-atlas.pdf) · [取色记录](https://github.com/dxlian/Scientific-Schematic-to-PPT/blob/v0.4.0/references/palette-evidence.json)
- 中文默认宋体，英文和数字默认 Times New Roman。用户图片与数据同时提供时，复绘记录区分需要保留的外观、应由新数据决定的曲线与标注，并在实际渲染后逐区对照。[复绘流程](https://github.com/dxlian/Scientific-Schematic-to-PPT/blob/v0.4.0/references/reference-redraw.md)
- Python 提供折线、散点、误差棒、多面板、阈值、极值、拟合及局部放大；R 提供分布及关系图；Origin 生成含原数据、可选平滑/拟合和原生曲线的 OPJU。[Python 规格](https://github.com/dxlian/Scientific-Schematic-to-PPT/blob/v0.4.0/references/data-plotting.md) · [R 与 Origin](https://github.com/dxlian/Scientific-Schematic-to-PPT/blob/v0.4.0/references/engine-r-origin.md)

## 本机验收

| 项目 | 本轮观察 |
| --- | --- |
| 模糊指令与主题 | 6 个贴近实验的中文指令分别命中裂隙、传质、酸蚀、加载、微流控、分层器件；范围外的星图请求返回待核对。选择器另覆盖中英文关键词、歧义、未知主题、手动覆盖以及图片锁色。 |
| 示意图还原与可编辑性 | 在独立生成的 1000 px 宽参考图与合成 CSV 案例上，通过 WPS 实际渲染及组合/取消组合。峰顶水平差 0.5 px，纵向差 0 px。PPT 内中英字体槽与原生形状通过 OOXML 审计。 |
| 数值和版式 | 两面板合成表包含不等间距、缺失观测和缺失误差。独立复算得到峰值 (6, 5)、首次阈值交点 (1, 2)、第二面板斜率 2、截距 1、R² 为 1。修正了对数坐标内曲线和阈值落点不一致、放大窗丢失误差棒和混排公式中文字缺字。 |
| 交付文件 | 检查了 Python 和 R 的矢量 PDF、可提取中英文字与 600 DPI PNG；独立打开了实际输出的 Origin 工程并核对原始列、SG 派生列、拟合系数和三条可编辑曲线。双面板矢量拼版保留两个源面板的文字及路径。 |

本轮材料包含合成实验数据和独立绘制的参考图。真实项目可使用同一流程记录首次渲染是否可用、每轮修复次数、最大锚点误差、未消除的遮挡，以及可编辑对象范围。不同来源图按自身分辨率、对象类型和数据可用性设定容差。
